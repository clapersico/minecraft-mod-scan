# Minecraft Mod Scanner

A Python-based tool for scanning Minecraft mods to check their versions and licenses.

## Description

Minecraft Mod Scanner is designed to help Minecraft server administrators, mod pack creators, and players manage their mod collections by providing automated scanning capabilities to:

- **Version Detection**: Identify the versions of installed Minecraft mods
- **License Checking**: Scan and report the licenses associated with mods
- **Compatibility Analysis**: Help ensure mod compatibility across different versions
- **Inventory Management**: Maintain an organized overview of installed mods
